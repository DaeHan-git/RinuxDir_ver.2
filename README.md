# LinuxLex — 리눅스 명령어 사전

사전 중심 테마의 정적 리눅스 명령어 사전입니다.

## 포함 기능

- 첫 접속 시 닫힌 책이 펼쳐지고 페이지 안으로 확대되는 인트로
- 리눅스 명령어 66개 검색 및 알파벳 색인
- 분류 필터, 책갈피, 학습 상태, 암기 카드
- 반응형 모바일 레이아웃
- GitHub Pages 자동 배포 워크플로

## GitHub Pages 배포

1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. 저장소의 **Settings → Pages**에서 Source를 **GitHub Actions**로 설정합니다.
3. `main` 브랜치에 push하면 `.github/workflows/pages.yml`이 `public/` 폴더를 GitHub Pages로 배포합니다.

정적 사이트의 시작 파일은 `public/index.html`입니다.
